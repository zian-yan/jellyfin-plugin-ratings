Ratings

Jellyfin 插件 · 多来源影视评分（MDBList / TMDb / 豆瓣 / AniList …）

仓库地址

https://raw.githubusercontent.com/zian-yan/jellyfin-plugin-ratings/main/docs/manifest.json

添加步骤

  1. 控制台 → 插件 → 右上角 仓库 → +
  2. 名称填 Ratings，URL 粘贴上面的地址，保存
  3. 切到 目录 标签，找到 Ratings，点安装
  4. 重启 Jellyfin，进入 插件 → Ratings → 设置，填入 API Key
